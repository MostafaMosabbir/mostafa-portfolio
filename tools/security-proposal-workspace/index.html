    Backup restoration / REQ-010

    Reload the fictional sample to run this exercise on its own.

    1. In CTL-010, set Implementation status to implemented, clear the Target date, and record that the fictional files were restored to a separate destination and the restore was reviewed.
    2. In EV-010, set the Evidence location or reference to DEMO-RESTORE-REVIEW-010 and the Evidence review date to October 27, 2026.
    3. Return to the comparison and review again. REQ-010 should become a supported draft. The separate integrity finding in REQ-015 remains open.

    An implemented status with notes that still describe an incomplete restore keeps the finding open. Review the notes and evidence together.
