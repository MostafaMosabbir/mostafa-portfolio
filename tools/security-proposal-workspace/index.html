Assessment settings

The freshness window is a configurable project rule, not a framework requirement.

01 / Requirement

What needs to be addressed?

Record the requirement, its source, and the person who reviewed whether the mapped controls cover it.

02 / Control and owner

What safeguard is recorded?

Link controls to requirements using their IDs. Separate multiple IDs with semicolons.

03 / Evidence and review

What evidence is recorded?

Link evidence records to controls using their IDs. The reference is recorded as text and is not opened.

04 / Findings

Review the recorded information

Checks apply to all mapped controls and evidence. A supported draft still needs human review.
