How the assessment works
  1. Read the requirements, controls, and evidence records.
  2. Validate IDs, mappings, dates, and allowed status values.
  3. Check implementation status, ownership, coverage review, and evidence freshness.
  4. Export the crosswalk, gaps, and review report for human review.

Evidence references are not opened or independently verified. Counts are not a compliance score.

This browser adaptation reimplements the desktop game's rules in Rust. The Rust code manages the board, movement, color matching, cascades, and score. It is compiled to WebAssembly, while JavaScript draws the game and handles browser input.

The simplified browser version does not save high scores or include every desktop feature.

The full tool runs locally in Python. This browser demonstration analyzes a separate six-ticket sample using JavaScript. It checks required fields, groups repeated subject wording, and flags resolved or closed tickets without notes. Repeated wording is a review candidate, not proof of the same root cause.

Built with HTML, CSS, and JavaScript. Published with GitHub Pages. The visual effects and project interactions run in the browser.

A local JavaScript prototype using fictional tickets and rule-based matching. Draft responses require human review.

The assessment engine runs locally in Python using the standard library. The published report is a fixed fictional example, not a live assessment service or a compliance determination.

The original desktop game uses Rust and ggez. This browser adaptation reimplements the game rules in Rust compiled to WebAssembly; JavaScript handles the browser display and controls. Closing the game resets the current session.

R validates the public CISA catalog and generates a monthly JSON snapshot. GitHub Actions checks daily; JavaScript displays the latest available snapshot and a bundled fallback when needed.

The Java source adapts a 2019 class project and saves locally. The independent browser demo uses JavaScript, does not run the Java application, and resets when the page refreshes.
