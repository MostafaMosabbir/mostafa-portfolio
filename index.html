HTML contains the content and structure. CSS controls the appearance. JavaScript controls project selection, search, the sample workflow, and switching between The Workbench and After Hours.

Read a fictional ticket, suggest a category, explain matching rules, and prepare an editable response draft. A person reviews the draft.

This prototype uses rules, not a live AI model.

  1. Read the requirements, controls, and evidence records.
  2. Validate IDs, mappings, dates, and allowed status values.
  3. Check implementation status, ownership, coverage review, and evidence freshness.
  4. Export the crosswalk, gaps, and review report for human review.

Evidence references are not opened or independently verified. Counts are not a compliance score.
