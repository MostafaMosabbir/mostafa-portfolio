# Initial homepage plan

## Audience and goal

Help recruiters and collaborators understand Mostafa's work quickly and follow links to evidence. Do not claim skills, employment, credentials, or accomplishments until they are confirmed.

## Page order

| Section | Content | Visitor action |
| --- | --- | --- |
| Header | Name and links to About, Projects, Cybersecurity, Contact | Navigate to a section |
| Introduction | Name, an accurate one-sentence professional focus, and a short explanation of the work showcased | View projects or GitHub |
| About | A brief personal introduction and skills demonstrated by linked work | Understand background |
| Selected Projects | Two or three case study cards with title, problem, contribution, technology, status, and links | Read a case study or inspect code |
| Cybersecurity | A separately labeled selection of authorized labs and defensive work | Read findings and evidence |
| Contact | GitHub and any approved public contact details; resume link only when available | Connect or review resume |
| Footer | Name and GitHub link | Return to profile |

The Rowan fishing capstone is excluded from the navigation, project cards, assets, and homepage content.

## Suggested visual direction

Use a restrained palette, readable typography, generous spacing, and consistent cards. Keep the introduction concise. Make evidence and project links easy to find.

## First implementation

Start with plain HTML and CSS:
- `index.html` at the repository root for homepage content.
- `styles/main.css` for responsive layout and styling.
- `assets/images/` for real screenshots.
- JavaScript only if an interaction requires it.

These website files are planned, not part of the current documentation starter. Select hosting after the page works locally. If using project-based hosting, verify paths under the repository subdirectory.

## Ready-to-publish criteria

- Introduction and project claims are accurate.
- No placeholder cards, broken links, or invented achievements.
- General projects and cybersecurity have distinct headings.
- Layout works on mobile and desktop.
- Semantic headings, descriptive links, visible keyboard focus, sufficient contrast, and image alt text are present.
- Contact and resume details are approved for public display.
- Rowan fishing capstone material is absent.
- Every featured case study links to code or useful evidence.
