# Scope and separation

| Work | Location | Homepage treatment |
| --- | --- | --- |
| Personal portfolio website and planning | This repository; root website files, docs/, assets/ | Main personal site |
| General portfolio case studies | projects/project-slug/README.md | Selected Projects |
| Standalone project implementations | Separate project repositories linked from case studies | Link to source and demo |
| Authorized cybersecurity work | cybersecurity/lab-slug/ | Separate Cybersecurity section |
| Rowan fishing capstone | Separate academic repository or workspace outside this repository | Excluded |

## Placement rules

1. Keep this repository focused on the personal website and public case studies.
2. Put general software project summaries in projects/.
3. Put cybersecurity summaries and sanitized lab evidence in cybersecurity/.
4. Keep all fishing capstone code, reports, data, screenshots, and documentation outside this repository.
5. Do not create a capstone folder, submodule, copied archive, or featured card here.

The separate capstone repository name and location are not assumed. This starter does not create or modify it.

A .gitignore file is a convenience, not a security boundary. Review changes before committing. Ignoring a file does not remove content already tracked by Git.
