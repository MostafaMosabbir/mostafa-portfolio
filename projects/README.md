# Portfolio projects

Store a short case study for each selected general software or technical project:

```text
projects/
└── project-slug/
    └── README.md
```

Use [the project template](../docs/project-template.md). Link to the project's own repository for source code and installation instructions. Add only real work; describe incomplete projects as in progress.

Prefer two or three strong, well-documented projects over many empty placeholders. Each should explain the problem, your contribution, implementation, evidence, and limitations.

Cybersecurity case studies belong in [cybersecurity/](../cybersecurity/README.md). The Rowan fishing capstone remains in its separate academic repository or workspace.
