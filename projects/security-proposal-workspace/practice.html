Restore a sample file locally

From the Security Proposal Workspace source folder, run the helper with a new output folder. It checks each backup copy against the saved SHA-256 hash before restoring and then checks the restored file. Read restore-results.json to see the successful restore and the rejection of a changed copy. This exercise needs Python and works without a cloud account.

python -B practice_restore.py --output my-restore-practice

For an optional cloud exercise, use an Azure lab environment with a test virtual machine protected by Azure Backup. Choose a recovery point and recover a sample file to a separate location. Microsoft Learn Azure file restore tutorial

Record for review

  • The sample file and backup copy, restore destination, result, and run date. For a cloud restore, include the selected recovery point and job result.
  • The original, backup, and restored SHA-256 hashes. Record whether each backup was accepted and whether a restore destination was created.
  • The backup scope and protection settings that still need review. The local file restore illustrates REQ-010. Rejecting the changed copy before restoring illustrates the separate integrity check in REQ-015.
