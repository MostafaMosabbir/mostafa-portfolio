# Mostafa Mosabbir — Personal Portfolio

A professional portfolio for presenting selected projects, technical skills, and cybersecurity learning through clear, verifiable evidence.

**Status:** Starter structure; the website has not been built or deployed.  
**Target:** Portfolio website and supporting GitHub projects ready by December 2026.

## Purpose

Help visitors understand what I build, how I approach problems, and where they can review my work. Project descriptions will identify my contribution, explain technical decisions, and link to working code or documented results.

## Content areas

- **Portfolio projects:** Selected software and technical project case studies in [projects/](projects/README.md). Larger project codebases should live in their own repositories, linked from their case studies.
- **Cybersecurity:** Public, authorized lab write-ups and defensive work in [cybersecurity/](cybersecurity/README.md), presented as a distinct website section.
- **Rowan fishing capstone:** A separate academic project maintained outside this repository. Do not copy its code, reports, datasets, or assets here.

See [scope and separation](docs/scope-and-separation.md) for placement rules.

## Website direction

The first version will use a simple static homepage with About, Selected Projects, Cybersecurity, and Contact sections. The [homepage plan](docs/homepage-plan.md) defines content and acceptance criteria. No framework or hosting service is configured yet.

## Working locally

Clone this repository, open it in an editor, and start with the Markdown documents:

```bash
git clone https://github.com/MostafaMosabbir/mostafa-portfolio.git
cd mostafa-portfolio
```

There are no dependencies, build commands, or tests in this documentation starter.
