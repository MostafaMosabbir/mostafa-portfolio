# Cybersecurity work

A distinct collection of authorized security labs, defensive analysis, and learning write-ups.

Recommended layout when a real lab is ready:

```text
cybersecurity/
└── lab-slug/
    ├── README.md
    └── evidence/
```

Use [the project template](../docs/project-template.md), adding:
- Lab environment and authorization scope.
- Defensive question or learning objective.
- Reproduction steps and tools actually used.
- Sanitized evidence, findings, and remediation.
- What the exercise demonstrates and what remains untested.

Publish only work you have permission to share. Remove credentials, personal information, and sensitive system details from evidence. Label simulations and lab findings clearly.

Possible future topics include log analysis, network traffic investigation, or a hardening checklist. These are ideas, not completed projects or claimed experience.

The homepage should give this work its own section. Do not include the Rowan fishing capstone here.
